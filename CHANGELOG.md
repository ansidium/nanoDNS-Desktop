# Changelog

## 0.2.1 — 2026-11-01

First public release of nanoDNS Desktop.

- Native Windows interface with editable DNS rules, priority exceptions,
  upstream settings and a searchable query log.
- 30 interface languages with Windows language detection and English fallback.
- Embedded regional CJK font subsets.
- Tray controls, optional Windows startup and selected-LAN DNS binding.
- PS5-inspired background that pauses while hidden or minimized.
- Portable Windows package, corresponding source archive and SHA-256 hashes.
