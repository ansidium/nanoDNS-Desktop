nanoDNS Desktop 0.2.1 — Windows 10 / 11 x64

1. Connect the computer and PS4 / PS5 to the same network before launching.
2. Extract the ZIP and run nanoDNS.exe. DNS starts automatically by default.
   Approve Windows firewall setup if prompted.
3. On the console, choose manual DNS and enter the app's address in both fields.
   Leave IP / DHCP and MTU automatic and do not use a proxy.

Keep the computer on and connected. If its IP changes, update both DNS fields.
Use UDP port 53. Stop DNS before changing the selected network adapter.
Closing the window keeps DNS running in the tray by default.
Choose Exit in the tray menu to stop it before updating.
Settings and logs: %LOCALAPPDATA%\NanoDNS Desktop
